# URL → Markdown → LLM 핸드오프

## 사용자에게 보이는 결과

사용자는 웹페이지 URL을 붙여넣어 본문을 깔끔한 마크다운으로 변환하고, 그 결과를 복사·`.md` 다운로드·ChatGPT/Claude로 바로 넘기는 방식 중 하나로 내보낼 수 있다.

승인된 화면 구조와 동작은 [prototype.html](prototype.html)에서 직접 확인할 수 있다(사용자 검토·승인 완료).

## 승인된 범위

1. **입력** — URL 붙여넣기 입력창, 지우기 버튼(입력값·결과·선택된 프롬프트를 모두 초기 상태로 리셋).
2. **변환** — defuddle 라이브러리로 본문을 추출해 마크다운을 생성.
3. **프롬프트 + 결과 확인** — 변환이 끝나면 입력 영역(변환하기 버튼) 바로 아래에 프롬프트(선택) 섹션이 먼저 나타나고, 그 아래에 페이지 제목·저자 헤더(있는 것만 표시) + 렌더링된 마크다운이 이어진다. 프롬프트 섹션은 변환 결과와 함께 나타나고 지우기와 함께 사라진다.
4. **내보내기**
   - 복사하기: 마크다운(프롬프트를 선택했다면 그 문구를 앞에 붙여서)을 클립보드로 복사.
   - `.md` 파일 다운로드: 마크다운 원문만(프롬프트 미포함).
   - ChatGPT로 열기 / Claude로 열기: (선택된 프롬프트 + 마크다운)을 클립보드에 자동 복사한 뒤 해당 서비스의 새 채팅 페이지를 새 탭으로 열기. 사용자가 붙여넣기(Ctrl+V)해서 완료.
5. **프롬프트** — 프리셋 3종(요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘), "직접 입력" 선택 시 텍스트 인풋 노출(세션 내 1회용, 저장 안 함), 프롬프트 미선택도 허용.
6. **다크모드 토글.**

## 관찰 가능한 승인 기준

- 유효한 기사 URL을 붙여넣고 변환하면 제목(가능하면 저자)과 렌더링된 마크다운이 표시된다.
- 프롬프트(선택) 섹션은 입력 영역(변환하기 버튼) 바로 아래, 결과 콘텐츠보다 위에 위치하며, 변환 결과와 함께 나타나고 지우기와 함께 사라진다.
- 지우기 버튼을 누르면 입력·결과·선택된 프롬프트가 모두 초기화된다.
- 복사하기를 누르면 클립보드에 마크다운이 담기며, 프롬프트를 선택한 상태였다면 그 문구가 맨 앞에 붙는다.
- `.md` 다운로드를 누르면 마크다운 원문(프롬프트 미포함)이 파일로 저장된다.
- ChatGPT로 열기 / Claude로 열기를 누르면 클립보드에 (프롬프트 + 마크다운)이 복사되고 새 탭에서 각 서비스의 새 채팅 화면이 열린다(자동 프리필 없음 — [llm-handoff-export](../../decisions/llm-handoff-export.md) 참조).
- 프리셋 프롬프트를 선택하면 즉시 적용되고, "직접 입력"을 선택하면 텍스트 인풋이 나타나며 리셋 시 사라진다(저장되지 않음).
- 다크모드 토글이 전체 UI의 라이트/다크 테마를 전환한다.

## 확정된 제약과 근거

- 본문 추출에는 defuddle 라이브러리를 사용한다(사용자 확정 요구사항). Node 환경에서 DOM 구현체와 함께 URL을 받아 `title`/`author`/`contentMarkdown` 등을 반환하는 것을 문서로 확인했다(https://defuddle.md/docs).
- ChatGPT/Claude로 열기는 URL 파라미터 자동 프리필이 아니라 "클립보드 복사 + 새 탭 열기" 방식으로 통일한다. ChatGPT의 `?q=` 프리필은 비공식·미문서화 동작이고 URL 길이 제한이 있어 긴 글 전체를 담을 수 없으며, Claude는 실측 결과 해당 방식이 동작하지 않는다(로그인 페이지로 리다이렉트, 프리필 없음). 자세한 근거는 [llm-handoff-export](../../decisions/llm-handoff-export.md) 참조.

## 가정 (저비용·번복 가능, 확정 아님)

- 변환은 URL을 붙여넣은 뒤 별도 액션(버튼 또는 Enter)으로 시작한다. 붙여넣는 즉시 자동 변환하지 않는다.
- 변환 실패(URL 무효, 접근 불가, 추출 실패 등) 시 입력창 근처에 에러 메시지를 보여주고 재시도할 수 있게 한다.
- 페이지 제목/저자 정보가 없으면 해당 필드는 표시하지 않는다.
- 마크다운은 렌더링된 미리보기만 제공한다(원문 텍스트 보기 토글 없음). 복사·다운로드는 내부적으로 원문 마크다운 텍스트를 사용한다.
- 프롬프트 프리픽스는 "복사하기"와 "ChatGPT/Claude로 열기"에만 적용되고, `.md` 다운로드에는 적용하지 않는다(다운로드는 순수 보관용 콘텐츠로 취급).
- 다크모드 토글의 기본값은 시스템 설정을 따르고, 토글로 수동 전환할 수 있다.
- 로그인/계정 없이 동작하는 1회성 세션형 도구다. 서버에 변환 이력이나 결과를 저장하지 않는다.
- UI 언어는 한국어 단일 언어로 한다(프리셋 프롬프트가 모두 한국어로 주어짐).

## 범위 밖

- 변환한 페이지를 앱 내에 저장해두고 목록으로 관리하는 라이브러리/보관함 기능은 포함하지 않는다. 이번 스코프는 1회성 변환·내보내기 흐름만 다루며, 사용자가 받은 `.md` 파일로 직접 관리한다. ([PRODUCT.md](../../../PRODUCT.md)에 남아 있던 "저장된 마크다운을 나중에 다시 찾아서 쓰는지" 미정 항목을, 이번 작업 범위에서는 "앱이 직접 관리하지 않음"으로 좁혀서 다룬다.)
- 사용자 계정, 로그인, 변환 기록 저장은 포함하지 않는다.
- ChatGPT·Claude 외 다른 LLM 서비스로 열기는 포함하지 않는다.
- 여러 URL을 한 번에 일괄 변환하는 기능은 포함하지 않는다.

## 유보된 사항

확인된 사항 없음 — 이번 세션에서 구현에 필요한 결정은 모두 확정하거나 가정으로 처리했다.

## 남은 위험

- 일부 웹사이트는 서버 측 요청을 봇으로 차단하거나(Cloudflare 등) JS 렌더링에 의존해, defuddle이 본문을 제대로 추출하지 못할 수 있다.
- ChatGPT의 `?q=` 프리필은 비공식 동작이라 예고 없이 바뀌거나 막힐 수 있다. 다만 이 스펙은 그 동작에 의존하지 않으므로(클립보드 복사 방식) 직접 영향은 제한적이다.
- 매우 긴 문서를 클립보드로 복사해 ChatGPT/Claude에 붙여넣을 때 대상 서비스의 입력 길이 제한에 걸릴 수 있다(내보내기 자체는 항상 성공하며, 붙여넣기 이후는 각 서비스의 제약을 따른다).
